# Jogo-adivinha-o-python
# 🎮 Jogo da Adivinhação

Um jogo simples de adivinhação desenvolvido em Python como parte dos meus estudos de lógica de programação.

## 📝 Sobre o projeto

O jogo desafia o jogador a adivinhar diferentes opções escolhidas aleatoriamente pelo computador.

Durante o jogo, o computador escolhe:

- 🔢 Um número entre 0 e 10
- 🔢 Um número entre 20 e 30
- 🐾 Um animal
- 🎨 Uma cor

O jogador tem uma chance para tentar acertar cada opção. Caso erre, o programa informa qual foi a escolha do computador.

## 🛠️ Tecnologias utilizadas

- Python
- Biblioteca `random`

## 📚 Conceitos praticados

Neste projeto pratiquei:

- `input()`
- `print()`
- `if` e `else`
- Comparação com `==`
- Conversão de dados com `int()`
- Listas
- `random.randint()`
- `random.choice()`
- Cores no terminal utilizando códigos ANSI
